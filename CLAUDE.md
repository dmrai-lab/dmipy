# dmipy — umbrella + docs (dmipy.org)

This repo is the **dmipy** brand umbrella: a thin meta-package (`pip install dmipy` → dmipy-sim,
dmipy-replay, dmipy-fit and dmipy-design, with dmipy-analytic under them; `dmipy[tract]` adds
dmipy-tract) and the source of the documentation site at dmipy.org. It holds **no package code**;
the packages are the sibling repos.

## Layout
- `pyproject.toml` — `dmipy` meta-package: the packages' version ranges; `[tract]`/`[docs]`/`[cuda12]`/
  `[cpu]`/`[test]` extras. No importable `dmipy` package.
- `mkdocs.yml`, `docs/` — MkDocs Material site → dmipy.org. `api.md` autodocs the *installed*
  packages with mkdocstrings, so the reference cannot drift from the code.
- `tools/` — everything generated on the site is generated by a script here, from the packages:
  `gen_constants.py`, `gen_catalog.py`, `gen_substrate.py`, `gen_analytic.py` (pages; the last is
  `docs/analytic/forms.md`, every dmipy-analytic form with its source), `gen_acquisition_figure.py`,
  `gen_explorer_data.py` (the sequence explorer's grid), `gen_signal_widget.py` (the landing
  widget's replay grid), `gen_spin_studio.py` (the spin studio's walk), `gen_brain_demo.py` (the
  brain page's tables), `gen_replay_guide.py` (`docs/replay/`: the replay guide copied from
  dmipy-sim's `docs/replay-guide/`, where it is written and tested -- edit it there) and
  `gen_step_law_page.py` (`docs/physics/step_law.md`, from dmipy-sim's `docs/step-law.md`);
  `run_snippets.py` executes every ```python block in `docs/`; `check_explorer.js`,
  `check_brain.js`, `check_signal_widget.js` and `check_spin_studio.{js,py}` exercise the
  interactive pages headlessly (the spin studio against dmipy-replay's vector-Bloch propagator);
  `install_packages.sh released|mains` is the one install of what a build documents.
- `.github/workflows/docs.yml` — deploys `main` → dmipy.org (root, the released packages) and
  `staging` → dmipy.org/dev/ (the packages' git mains, its own venv, snippets run first).
  `docs-pr.yml` — on a pull request: snippets, the headless checks, strict build; a pull request
  into `main` with the released packages, any other with the git mains.
- `papers/` — reproducible manuscripts; index at `papers/README.md`.

## Rules for the docs
- **Every code block runs in CI.** A block that cannot run (needs a file, a scanner, the 2019
  package) starts with `# docs: skip`, and its dmipy imports and module attributes are still
  resolved against the installed packages; one that reads a cached artefact next to its page
  starts with `# docs: cwd`. Keep examples small enough for a CPU runner (tens of seconds).
- **The browser draws, the engine computes.** Interactive pages look up data a `tools/gen_*`
  script produced with the packages; the one JavaScript integrator (the spin studio) is checked
  against the engine in CI. Do not add physics in JavaScript without a parity check.
- **One page, one question, one runnable example at the top.** Physics exposition goes under
  *Physics*; derivations stay reachable by link but out of the tabs. Do not restate docstrings.
- The brain demo (`phantoms/brain.md` + `studio/brain.html`, data in `studio/brain_data/` from
  `tools/gen_brain_demo.py`, checked by `tools/check_brain.js`) is the brain page; `studio/index.md`
  lists the interactive pages.
- `/dev/` (`staging`) is the next site and the root (`main`) the released one; `main` takes
  `staging` by a pull request from `staging`.
- The replay paper is arXiv:2611.01758 (2026-11-01); `docs/publications.md` holds its link and BibTeX.

## Relationships (don't conflate)
- **dmipy** (this repo) = the public computational-engine brand + docs + paper.
- **dmipy-analytic / dmipy-replay / dmipy-sim / dmipy-fit / dmipy-design / dmipy-tract** = the
  packages (source of truth for the API docs); `docs/packages.md` says what each one is.
- **dmrai-lab** = the organisation (dmrai-lab.org). dmipy.org is the tool; dmrai-lab.org is the lab.
  Echo one line of the manifesto and link back; do not duplicate it.
