# Sequence explorer

Pick a family, move the knobs, watch the object: the physical gradient, the RF events, the
effective gradient, q(t), the b-value and whether it refocuses. Every curve you see was built by
`dmipy_sim`'s builders over a grid of parameters and stored; the page looks up and draws, it does
not re-implement the physics.

The grid is generated by `tools/gen_explorer_data.py` in this repository; the page's footer names
the dmipy-sim version it was built with. To build the same sequence yourself:

```python
# docs: skip  (the knobs on the page; any point on the grid is this call)
import dmipy_sim as ds
seq = ds.pgse([[1, 0, 0]], delta=0.010, Delta=0.030, bvalues=[1e9], slew_rate=200.0)
```
