# Studio

In-browser demonstrations that run the real dmipy-sim physics **client-side** — no install, no server, nothing to download.

## Bloch studio — white matter, real pulses

Build an RF + gradient sequence (PGSE · PGSTE · CPMG · OGSE) from real baked B1 pulses, then sweep the B0 orientation, susceptibility, off-resonance and B1⁺ inhomogeneity and watch the magnetization evolve — a live, client-side vector-Bloch simulation over a Monte-Carlo white-matter walk, on a synthetic circular substrate or an in-vivo brain slice.
